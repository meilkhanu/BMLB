Anime.js 演示

Anime.js v4 — 一个 API 动画一切。下面三个 demo 分别用到 stagger、 createDrawable / morphTo、createDraggable + createSpring。

dot-grid.html
stagger13 × 13 grid
const options = {
  grid: [13, 13],
  from: 'center',
};

createTimeline()
  .add('.dot', {
    scale: stagger([1.1, .75], options),
    ease: 'inOutQuad',
  }, stagger(200, options));

wave 从中心向外扩散；burst 换成 from: 'last' 并反转方向。 核心是 stagger() 的 grid 参数——它把一维索引映射成二维坐标， 动画就自动带上空间感。

circuit.svg
svgdrawable + morphTo
// 描边：沿路径画线
animate(createDrawable('.c-a'), {
  draw: ['0 0', '0 1'],
  duration: 900,
  ease: 'inOutQuad',
});

// 变形：把 A 路径 morph 成 B
animate('.c-a', {
  d: morphTo('.c-b'),
  duration: 700,
});

createDrawable() 把 path 变成可控制的 draw 属性（起止点都是 0~1）； morphTo() 要求两条 path 的命令结构一致，否则插值会跳。 这里 c-a / c-b 是同一结构的上下两条折线。

draggable.html
DRAG

按住拖动，松手回弹 · 手机可触摸

draggablereleaseEase: spring
createDraggable('#dragCircle', {
  releaseEase: createSpring({
    stiffness: 120,
    damping: 6,
  })
});

createSpring() 返回一个真实物理弹簧缓动—— stiffness 越大越硬、回弹越快，damping 越小晃动越久。 拖到边缘再松手，能看到明显的过冲和振荡。
